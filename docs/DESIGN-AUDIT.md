# Аудит интерфейса Асси, 3 ноября 2026

Сохранено утверждённое направление: графитовые поверхности, мятный акцент, разделы
«Устройства», «Сеансы», «Настройки», адаптивные области прокрутки. Основание:
исходники реального клиента, визуальная проверка в браузере и независимый review.
Использованы better-ui и web-design-guidelines; сверены актуальные
[Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md).

## Исправлено

| Проблема | Результат |
|---|---|
| Выбранный на телефоне фильтр скрывал устройства после расширения окна, а переключатель исчезал | Фильтры доступны и в sidebar; заголовок соответствует группе |
| Фоновое завершение добавления/удаления пересоздавало форму настроек | Обновляется только адресная книга; черновик имени сохраняется |
| Ошибки формы были общими и не связанными с полем | Inline-ошибки, aria-invalid/aria-describedby, фокус неверного поля |
| Вкладки сеансов не имели связанной панели | tab/tabpanel связаны ID, сохранена навигация стрелками |
| Изменение сеанса во время диалога оставляло устаревший экран | Отложенное обновление при закрытии диалога |

Новые состояния соединения показывают реальные данные Rust-ядра. Входящий запрос
содержит имя отправителя с пояснением о его непроверенности; управление выключено
по умолчанию. Постоянная панель показывает открытый доступ и позволяет прекратить
приём/сеанс. История ограничена текущим запуском и явно так подписана.

## Проверено

- Экран согласия: 320×568, 360×640, 390×844, 600×400, 760×500, 761×500,
  1024×600, 1440×900. Горизонтального переполнения документа/основной области нет.
- Просмотрщик без кадра: 320×568, 600×360, 761×500, 1440×900; переполнения нет.
- Переход фильтра «Рабочие» с мобильной ширины на desktop; переключатель доступен.
- Пустое имя из пробелов: показана ошибка, фокус возвращается в поле.
- Регрессионные тесты поздних ответов диалога и очереди событий ввода.

Это браузерная проверка реальной разметки с отдельным тестовым источником состояния,
не доказательство работы нативной передачи экрана. Измерения:
`.validation/core-responsive.json`; снимок `.validation/core-consent-mobile.png`.

## Остаётся проверить вручную

VoiceOver/TalkBack, программную клавиатуру Android, физические сенсорные устройства,
масштабирование текста и системный контраст. Поддержка экранных дикторов не заявлена
как полностью сертифицированная. Визуальный стиль дальше менять не требуется;
следующие изменения должны исходить из реальных сценариев использования.

## Дополнение 0.3.0

Добавлен отдельный блок подтверждения/прогресса файла и переключатель direct/relay.
Прогресс обновляет только свой блок, не теряя фокус удалённого экрана. Постоянное
уведомление о входящем файле переводит к его подтверждению. Кнопка прекращения
доступа получила цвет опасного действия. Android-текст учитывает выбор отдельного
приложения системой. 18 сочетаний состояний/размеров прошли проверку переполнения,
см. `.validation/v3-responsive.json`; это browser fixture, не реальный MediaProjection.
