# Общие пометки поверх рабочего стола

Окно `annotations-overlay` — отдельная прозрачная поверхность только для чтения.
Показывается на основном мониторе владельца активного подтверждённого сеанса;
не получает фокус и пропускает мышь к приложениям под ним. Отдельное разрешение
на удалённый ввод для пометок не требуется: пометки не отправляют ввод в ОС.
Владелец может отключить наложение в интерфейсе Асси. На завершении сеанса окно
уничтожается, чтобы старые пометки не появились в следующем подключении.

Интеграция: `overlay::supported()`, `overlay::sync(app, active)` и
`overlay::hide(app)`. Вызывать из сериализованного жизненного цикла Remote.
`active` должен учитывать роль host, подтверждённое состояние Active и локальный
переключатель наложения. Перед медленной очисткой файлов необходимо вызвать hide.
IPC `session_overlay_snapshot` возвращает `Option<AnnotationSnapshot>` только
для разрешённого локального наложения текущего host-сеанса. Единственное разрешение
окна — эта команда; основные команды приложения ему не предоставляются.

## Поддержка

- macOS: используется прозрачный Tauri WebviewWindow с `content_protected(true)`.
  В установленном Tauri 2.12.5 / Tao это NSWindowSharingNone; текущий xcap 0.9.8
  захватывает CGWindowListCreateImage. Наложение должно исключаться из кадров,
  иначе зритель увидит и JPEG-пометки, и векторный слой. Требуется проверка на
  физическом Mac с разрешением записи экрана; автоматически такой захват не запускался.
- Windows: Tao устанавливает WDA_EXCLUDEFROMCAPTURE. Надёжное исключение требует
  Windows 10 2004 или новее и совместимого пути захвата. Старые версии могут
  показывать защищённую область чёрной. Нужна физическая проверка, включая DPI.
- Linux и Android: наложение поверх других приложений пока выключено. Общая доска
  остаётся в интерфейсе сеанса. Linux требует исключения окна из захвата; Android —
  отдельного системного разрешения/нативного окна, которого эта реализация не запрашивает.

`transparent` в заблокированной версии Tauri 2.12.5 доступен без прежнего флага
macOS private API. Никакие дополнительные entitlements не добавлялись.
Размер/позиция окна берутся в физических координатах основного монитора Tauri;
штрихи нормализованы относительно всей захватываемой поверхности. Толщина:
`max(1px, width * min(viewportWidth, viewportHeight) / 720)`.

Проверка выпусков: прозрачность без чёрного фона; отсутствие захвата наложения;
отсутствие перехвата кликов/фокуса; Retina/125%/150% scaling; изменение монитора;
завершение/повторный сеанс; macOS Spaces и полноэкранные приложения. Always-on-top
не обещает отображение поверх защищённых системных поверхностей.

Источники: [Tauri Window API](https://v2.tauri.app/reference/javascript/api/namespacewindow/),
[Windows SetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity),
[Apple NSWindowSharingType](https://developer.apple.com/documentation/appkit/nswindow/sharingtype).
Точные вызовы также проверены в локальных исходниках Tauri 2.12.5, Tao и xcap 0.9.8.
