# Реализация рабочего ядра — 2026-11-03

Разрешение: пользователь поручил аудит UI и завершение ядра. Рабочие изменения продолжаются без повторного подтверждения. Публикации, внешнего развёртывания и коммитов этот план не включает.

1. Аудит UI: правила Vercel, доступность форм, цели касания, состояния сети/согласия, сохранение утверждённого графитово-мятного дизайна.
2. Прямой transport Rust: TLS через rustls, приглашение с сертификатом и случайным токеном; локальное подтверждение с ID запроса, тайм-ауты, ограниченные очереди, бинарные кадры, отзыв согласия.
3. Платформенные адаптеры: desktop capture JPEG и конечный набор событий ввода; Android viewer. Разрешения ОС остаются обязательны. Нет тестового захвата реального пользовательского экрана без явного действия пользователя.
4. Интеграция Tauri: команды приёма/подключения/согласия/завершения, отдельная передача бинарного кадра, отображение состояний и удалённого изображения в UI.
5. Проверки: реальные localhost TLS endpoints со синтетическим изображением, отказ неверному приглашению и правам, закрытие/отключение/лимиты, compile adapters, audit responsive UI, macOS+Android builds, independent correctness/security review.

Критерий этого этапа: рабочий прямой сеанс между двумя клиентами, без демонстрационных таймеров. Облачные коды, NAT traversal/relay, оптимизированный H264/AV1 медиатракт и Android-host MediaProjection отдельные платформенные этапы; не выдавать их за реализованные.

## Продолжение 0.3 — поручение «Делай»

1. Self-host relay: исходящие TLS-соединения обеих сторон, ограниченные комнаты
   с expiry, затем неизменное end-to-end TLS внутри туннеля. Сервер не получает
   сертификат/секрет внутреннего приглашения и содержимое сеанса. Короткий код
   без дополнительной проверки личности не заменяет защищённое приглашение.
2. Передача файла в текущем сеансе: native picker, отдельное согласие получателя,
   chunk streaming, SHA-256/размер, временный файл и no-clobber publication;
   отмена/разрыв удаляют недокачанные данные. Никаких произвольных путей от WebView.
3. Android host: локальный Tauri plugin с MediaProjection consent,
   foreground service, bounded latest JPEG, stop/revocation; только просмотр.
4. UI интеграция, настоящие loopback TLS relay/file тесты, build macOS/Android,
   независимое security/correctness review. Публичный deploy не входит в поручение;
   физические OS permissions не автоматизируются без пользователя.

Владение: relay_server — crates/assi-relay; session_v3 — crates/assi-session;
android_capture — apps/client/android-host; primary — native/UI integration/docs.
